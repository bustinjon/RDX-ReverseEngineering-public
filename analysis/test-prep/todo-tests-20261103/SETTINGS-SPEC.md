# Hackura Settings: agreed layout (operator, 2026-11-07)

For the next build after T110. Compact buttons, no scrolling on the 1920x720 screen: use columns and submenus.

## Main screen
- Screen size: Smaller / Standard
- Volume popup: On / Off
- Volume popup size: Small / Medium / Large
- Map colours: Auto / Day / Night
- Absolute touchpad: On / Off
- Separate navigation volume: On / Off
- Buttons ›
- Phone & devices ›
- Developer ›
- Reset all

## Buttons ›
Every mapping is listed with On / Off, so people pick their own:
- Home: Honda Home (also from any Honda menu while AA runs)
- Hold Back: Honda screen
- Side-panel press while AA is minimized: back to AA
- Side-panel press while AA is showing: open Gemini (press again to close it)
- Hold side panel: Settings. If off, Settings still opens from the Hackura tile with no phone connected
- Hold console skip-forward: map colours
- Console and wheel skip: next / previous track
- Knob and power button: play / pause
- Talk button: open Gemini instead of Acura voice (only if the takeover is made to work)

## Phone & devices ›
- Every recently plugged phone and dongle, the main phone included, each Enabled / Disabled.
- Names: the USB product name for now (for example "smartBox"). The setup tool will let owners name each device.
- If the main phone is disabled, AA will not start on it until it is enabled again.

## Developer ›
- Honda audio source; track info to Honda screens; Maps turn-by-turn to Honda screens (on by default)
- Remember this phone (no USB popups)
- Start AA when plugged in while driving
- Start without laptop after power-off
- Auto-accept: status, plus a "Turn on now" button
- Car GPS to phone
- Research only: wireless announce, Bluetooth probe, Wi-Fi Direct test
